# 瓦尔登：湖畔的一天

Unity 6 / URP 的第一人称湖畔生活 demo，**2026 可玩原型 02**。玩家在小木屋、菜园、林间小路和湖岸之间自由活动，拾柴、取水、种菜、钓鱼与做饭，再找个位置坐下欣赏风景。食物用于生活体验与手记记录，玩家可以自由安排日常。

## 运行

- Windows 02 版：运行 `Builds/WaldenLakeUpdate02/WaldenLake.exe`，保持同目录的数据文件夹与 DLL 完整。
- Unity 编辑器：使用 **6000.0.66f2** 打开 `Walden_Lake` 文件夹，选择菜单 **Walden → Play Demo**。
- 或打开 `Assets/Scenes/WaldenDemo.unity` 后按 Play。世界在进入 Play 时自动生成，编辑模式场景只有入口对象是正常现象。
- 首次自行打开源码时，先选择 **Walden → Open Demo Scene**，生成并保存运行时使用的基础材质。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 行走 |
| 鼠标 | 环顾 |
| Shift | 快走 |
| E | 拾取、取水、播种/浇水/收获、使用炉灶与料理台、端茶/汤、坐下、起身、睡觉；垂钓时收线 |
| F | 喝手中的茶或吃手中的热汤 |
| X | 结束垂钓 |
| Tab | 打开/合上生活手记 |
| Esc | 暂停、音量与鼠标设置 |
| H | 收起/展开操作提示 |
| F5 | 手动保存 |

看向可互动对象，会在屏幕下方出现提示；距离需在约三米以内。树林中的落枝可拾取；码头尽头的水桶可取水。一份柴火和一份水可以在屋内炉灶烧一壶茶，约九秒后在窗边桌上的茶盘端起。拿着茶或汤走到屋内或湖边座椅，按 E 坐下、F 享用、E 起身。

床用于睡到次日并保存。库存上限为柴火 12、水 3、蔬菜 12、湖鱼 6、热汤 6；落枝次日补充，库存与菜园状态保留。一天约十二分钟，夜晚可自由停留。存档还会在每分钟、手动保存和正常退出时写入；重新启动后回到小屋旁的安全位置。

## 菜园、料理与钓鱼

门前有三块菜畦。看向空地按 E 播种，再按 E 消耗一份清水浇灌；每天每块地可浇水一次。经过**两个浇过水的夜晚**后成熟，按 E 收获两份蔬菜，再重新播种。漏浇只会暂停生长，植物会保留已有进度。可以按“播种、浇水、睡一晚、再次浇水、再睡一晚、收获”完成一次种植循环；手记随时显示各块菜畦的状态。

初到湖边备有两份蔬菜，可以先拾柴取水，去屋内料理台尝试做汤。菜单中选择食谱开火，约十二秒后得到一份热汤；在窗边桌上的汤碗处按 E 端起，再按 F 用餐。

| 食谱 | 材料 | 成品 |
| --- | --- | --- |
| 田园蔬菜汤 | 蔬菜 2、清水 1、柴火 1 | 热汤 1 |
| 湖岸鲜鱼汤 | 湖鱼 1、蔬菜 1、清水 1、柴火 1 | 热汤 1 |

看向码头竿架按 E 开始垂钓，等待约 8–12 秒。浮漂动了以后，在六秒内按 E 收线可得到一条湖鱼；提前收线或按 X 结束垂钓会空手收竿。暂停或打开生活手记时，等待与咬钩计时会一起暂停。

生活手记记录当天与累计的收获、钓鱼、用餐和喝茶次数，也说明菜园的跨日生长规则。每天可以只照料一块地，或只在湖边休息。

## 存档

Windows 存档位置：`%USERPROFILE%/AppData/LocalLow/WaldenStudio/Walden Lake/walden-day.json`。上一份完整存档保存在 `.backup` 文件，写入使用临时文件与替换；主文件损坏时尝试读取备份。游戏没有新开存档按钮，测试过程使用隔离存档。

02 版会迁移旧版 v1 存档，保留原有天数、物资、喝茶记录与生活进度，并补齐菜园、食材和料理数据。

## 源码结构

- `WaldenGame`：生活循环、种植、料理、垂钓、物资、交互、时间、暂停、睡眠与存档入口。
- `WaldenWorld`：固定随机种子的程序化木屋、菜园、树林、湖岸、家具与拾取物。
- `WaldenPlayer`：第一人称移动、碰撞、坐姿与手持茶杯或汤碗。
- `WaldenAtmosphere`：昼夜、雾、合成环境声与交互音效。
- `WaldenUI`：中文引导、物资与进度 HUD、料理菜单、垂钓提示、生活手记与设置。
- `WaldenState` / `WaldenSave`：序列化数据、版本迁移、容量限制与备份恢复。
- `WaldenBuild`：编辑器入口、材质准备与 Windows 构建。

场景与声音均由代码生成；美术为简化的低多边形原型。菜园跨日生长与食材消耗构成轻量经营循环，后续可以逐步替换正式资产并扩展日常活动。

## 构建与验证

在 Unity 菜单选择 **Walden → Build Windows Demo**，或命令行：

```text
Unity.exe -batchmode -quit -projectPath <仓库>/Walden_Lake -executeMethod Walden.Editor.WaldenBuild.BuildWindows -logFile <日志路径>
```

可执行文件的隔离冒烟验证：

```text
WaldenLake.exe -waldenSmokeTest -waldenOutput <绝对输出目录> -screen-width 1280 -screen-height 720 -logFile <日志路径>
```

此模式验证生活循环、库存、次日、门口通行与存档恢复，并输出 JSON 报告与画面截图；完成后自动退出，不使用正常游玩的存档。
